About Us

EduPulse is a dedicated Student Feedback Analysis System built to bridge the gap between students and academic departments. By collecting structured course and faculty evaluations across B.Tech branches and sections, EduPulse transforms student voices into transparent visual analytics for continuous curriculum improvement.

Features

Branch-Specific Courses

Dynamic subject selection tailored to 15+ engineering branches including CSE, AI-ML, Data Science, ECE, and more.

Automated Data Analysis

Powered by Python, Pandas, NumPy, and Matplotlib to compute course averages and rating distributions automatically.

Visual Rating Charts

Generates real-time course and section-wise teacher performance bar charts for quick administrative review.

Secure Admin Portal

Protected administrator login and comprehensive dashboard backed by a relational MySQL database.
